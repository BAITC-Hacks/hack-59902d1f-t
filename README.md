# Beeline Tariff Marketing Campaigns Agent

## Обзор

Агент управления маркетинговыми кампаниями для оптимизации переходов между тарифами. Решение использует **адаптивную разведку (adaptive exploration)** с пилотами, **байесовскую оценку неопределённости** и **портфельную оптимизацию** для максимизации прибыли в рамках ограничений бюджета.

### Ключевые метрики
- **Базовая выручка:** 150,641,084 у.е. (сумма predicted_arpu всех абонентов)
- **Бюджет:** 100,000 у.е.
- **Максимум контактов:** 15,000
- **Максимум кампаний:** 10
- **Максимум пилотов:** 20

---

## Архитектура решения

### 1️⃣ **Стадия 1: Анализ сегментов** (`SegmentAnalyzer`)

Идентифицируем ключевые клиентские сегменты по комбинации:
- **ARPU-сегмент:** LOW (<1000), MID (1000-5000), HIGH (>5000)
- **Data-сегмент:** NON_USER (0 MB), LITE (0-2000 MB), HEAVY (>2000 MB)
- **Call-сегмент:** LOW, MEDIUM, HIGH

**Почему это важно:**
- Высокоценные клиенты (HIGH ARPU + HEAVY data) — приоритет для personal touch каналов (звонок)
- Средние клиенты — цифровая реклама
- Low ARPU с потенциалом — SMS/push для экономии бюджета

### 2️⃣ **Стадия 2: Адаптивная разведка с пилотами**

#### Проблема неполной информации
История может описывать другую аудиторию. Пилот — единственный способ узнать эффект на целевой выборке.

#### Стратегия пилотов
1. **Приоритизация по информационной ценности**
   - High-value upsell (HIGH ARPU + HEAVY data → premium tariff)
   - Mid-value premium (MID ARPU + HEAVY data)
   - Growth segment (LOW ARPU + HEAVY data)

2. **Адаптивный размер выборки**
   - Пилот 30 клиентов: доступен, но ~25% ошибок
   - Пилот 150 клиентов: хороший баланс
   - Пилот 200 клиентов: надёжный, но дорогой

3. **Байесовская уверенность**
```python
confidence(n_samples) = 1 - exp(-n_samples / 100)
```
Меньше выборка → ниже уверенность → консервативнее используем результат

#### Выбор канала для пилотов
- Начинаем с SMS (стоит 4 у.е., эффективен на 65%)
- Для HIGH ARPU сегмента пробуем digital_ads (22 у.е., 85% эффективность)

### 3️⃣ **Стадия 3: Портфельная оптимизация**

#### Генерация кандидатов
```
Источник 1: Успешные пилоты
  - Берём те, где mean_arpu_change > 50 у.е.

Источник 2: Эвристики
  - Высокие тарифы часто работают для HIGH ARPU сегментов
```

#### Оценка кандидатов (Expected Value)
```
EV(campaign) = (ARPU_change × channel_effectiveness × confidence × conversion_rate) 
               - channel_cost_per_contact
```

**Пример расчёта:**
- Пилот показал: mean_arpu_change=150, std=50, n=100
- Confidence = 1 - exp(-100/100) = 0.632
- Channel = digital_ads: cost=22, effectiveness=0.85
- Conversion_rate = 0.35 (типовая)

```
EV = (150 × 0.85 × 0.632 × 0.35) - 22 = 28.1 - 22 = 6.1 у.е./клиент
```

#### Жадная оптимизация с ограничениями
```python
1. Сортируем кандидаты по EV
2. Выбираем лучшие, пока не исчерпаны:
   - Budget (100,000 у.е.)
   - Contacts (15,000)
   - Campaigns (10)
   - Per-campaign size (5,000)
```

## Ключевые особенности

### 🎯 Учёт неопределённости
- Пилот на 30 клиентах → confidence ≈ 0.26
- Пилот на 150 клиентах → confidence ≈ 0.78
- Результаты консервативнее для малых пилотов

### 💰 Оптимизация по ценности сегмента
```
HIGH ARPU → call (дорого, но эффективно для VIP)
MID ARPU → digital_ads (баланс)
LOW ARPU → sms/push (экономно)
```

### 🔄 Адаптивность
- Пилоты выбираются на основе уже известных эффектов
- Если пилот показал отличный результат, ищем похожие сегменты
- Раннее завершение разведки, если найден очень хороший сигнал

### 📊 Не переоптимизируем под мок
- Логика основана на принципах, а не на зашитых константах
- Confidence-взвешивание защищает от случайных выбросов
- Works on different seed values

## Примеры результатов

### Пример 1: High-Value Upsell
```json
{
  "campaign_name": "Premium_Upsell_tariff_18",
  "target_tariff": "tariff_18",
  "channel": "call",
  "filter_arpu_segment": "HIGH",
  "filter_data_segment": "HEAVY"
}
```
- Цель: 250 клиентов (HIGH ARPU, HEAVY data)
- Канал: звонок (160 у.е./контакт × 250 = 40,000 у.е.)
- Ожидаемый прирост ARPU: 150 у.е./клиент × 0.35 (конверсия) = 52.5 у.е./клиент
- Чистая прибыль: (52.5 × 250) - 40,000 = 13,125 - 40,000 = **-26,875** (убыточно!)

**Реальная калькуляция:**
```
Ожидаемый прирост ARPU × confidence × conversion × channel_eff
= 150 × 0.632 × 0.35 × 1.20 = 39.8 у.е./клиент
Чистая прибыль: (39.8 × 250) - 40,000 = 9,950 - 40,000 = минус (всё равно убыточно)
```

**Это показывает, что:**
- Даже дорогие каналы нужно использовать осторожно
- Confidence-взвешивание защищает от переоптимизма
- Нужна реальная информация из пилотов!

### Пример 2: Экономный рост
```json
{
  "campaign_name": "Growth_SMS_tariff_12",
  "target_tariff": "tariff_12",
  "channel": "sms",
  "filter_arpu_segment": "MID",
  "filter_data_segment": "HEAVY"
}
```
- Цель: 800 клиентов
- Канал: SMS (4 у.е./контакт × 800 = 3,200 у.е.)
- Ожидаемый прирост: 80 у.е./клиент × 0.75 (confidence) × 0.35 (conversion) × 0.65 (эффективность) = 13.65 у.е./клиент
- Чистая прибыль: (13.65 × 800) - 3,200 = 10,920 - 3,200 = **7,720 у.е.** ✅

## Оценка результатов

### Пилотная фаза
Используем ~20% бюджета (20,000 у.е.) для 5-8 пилотов, чтобы понять эффекты на реальной целевой выборке.

### Финальные кампании
Используем оставшиеся 80,000 у.е. для 5-10 высокоуверенных кампаний.

### Успех измеряется
```
Чистый результат = Прирост ARPU (по уникальным абонентам) 
                   - Затраты на коммуникацию
```

Победитель: максимум чистого результата в рамках ограничений.
